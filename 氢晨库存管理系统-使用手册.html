1. 系统概述

1.1 系统简介

氢晨库存管理系统是一套智能仓储管理平台，通过与汇川Easy522 PLC（Modbus TCP协议）通信，实现自动化立库的 入库、出库、货位管理、设备监控 等全流程管理功能。

1.2 系统架构

┌─────────────┐     Modbus TCP     ┌──────────────┐
│  汇川Easy522 │ ◄──────────────► │  后端API服务  │
│    PLC       │    端口:502      │  端口:5000    │
└─────────────┘                   └──────┬───────┘
                                         │ HTTP/JSON
                                         ▼
                                  ┌──────────────┐
                                  │  前端Web界面  │
                                  │  浏览器访问   │
                                  └──────────────┘

2. 登录与账号

2.1 登录系统

  1. 打开浏览器访问 http://服务器IP:5000
  2. 输入用户名和密码
  3. 点击 登录 按钮

2.2 退出登录

点击侧边栏底部的 退出登录 按钮即可退出系统。

2.3 账号权限说明

  • 管理员（Admin）：所有功能可用，包括用户管理、角色权限配置
  • 操作员（Operator）：入库、出库、查询、预警配置等功能
  • 查看员（Viewer）：仅可查看仪表盘、货位、台账、报表数据

3. 仪表盘

仪表盘是系统的首页，展示整体运营概况。

3.1 指标卡片

指标 说明
📥 今日入库 当天入库的工件数量
📤 今日出库 当天出库的工件数量
🔴 占用库位 当前已占用的库位数量
🟢 空闲库位 当前空闲的库位数量（不含出入库口）
⚠️ 库存预警 库存数量预警状态（正常/低于下限/高于上限）

3.2 库位可视化

以2排×4列×8层的立体货架图形式展示所有库位的占用状态：

  • 🟢 绿色：空闲库位，显示内部编号
  • 🔴 红色：已占用库位
  • 🚪 总出入口：1排1列1层

点击任意库位可查看详细信息。

3.3 设备运行状态

实时显示堆垛机PLC的连接状态、立库状态、运行模式等关键信息。

4. 入库管理

4.1 入库流程

填写信息 → 点击"入库确认" → PLC任务执行 → 完成

4.2 填写入库信息

字段 说明 必填
托盘号 扫描枪输入或手动输入，自动补零三位 是
工装号 工件工装编号 否
项目号 所属项目编号 否
型号 工件型号 否
工单号 生产工单号 否
电解槽编号 电解槽编号（批次入库用） 否
组件节数 组件节数 否
客户名称 客户名称 否
操作人员 自动填入当前登录用户 自动
备注 入库备注信息 否

4.3 托盘号扫描

  • 支持扫码枪输入，自动提取数字并补零三位（如 1 → 001）
  • 再次扫码时自动全选清空旧值
  • 可选从下拉列表中选择已有托盘号

4.4 PLC入库任务

点击 入库确认 后，系统自动执行以下步骤并在弹窗中显示进度：

  1. 查询PLC状态 — 检测立库是否空闲（D4009=1）
  2. 查询推荐货位 — 根据托盘号匹配内部编号，自动推荐空闲货位
  3. 发送PLC指令 — 写入D2022~D2026寄存器（动作码=3），逐条显示写入日志
  4. 等待任务完成 — 每秒检测D4009状态和D4014任务完成标志
  5. 写入数据库 — 任务完成后自动记录入库数据

注意事项：

  • 立库状态为3（故障中）或4（暂停中）时无法入库
  • 第1排第1列的库位，层数自动减1后发送给PLC
  • 写入指令后等待3秒检测PLC状态
  • 等待最长60秒，超时自动终止
  • 出现故障或暂停自动中断任务

5. 出库管理

5.1 出库流程

在清单选中工件 → 点击"执行出库" → PLC任务执行 → 完成

5.2 在库清单

以表格形式展示所有在库工件，支持：

  • 搜索：按托盘号、型号、货位号等关键字搜索
  • 筛选：按型号、项目号筛选
  • 选择：点击行选中要出库的工件

5.3 PLC出库任务

点击 执行出库 后：

  1. 查询PLC状态 — 检测立库是否空闲
  2. 发送出库指令 — 从工件记录解析货位排/列/层，写入PLC（动作码=2）
  3. 等待任务完成 — 监测D4009状态和D4014任务完成标志
  4. 写入数据库 — 任务完成后自动删除库存记录并生成出库台账

5.4 出库故障处理

当出库任务因PLC故障中断时，故障任务会记录在 出库故障任务 列表中：

  • 点击 🔧 故障处理 打开处理弹窗
  • ✅ 已处理出库 — 清除库存数据：确认出库已完成，清除库存数据
  • 🔄 未处理出库 — 保留库存数据：出库未完成，保留库存数据（危险操作，需折叠展开）

6. 货位管理

6.1 库位搜索与编辑

以表格形式展示所有库位，支持：

  • 搜索：按货位号、内部编号、位置搜索
  • 筛选：按空闲/占用/禁用状态筛选
  • 编辑：点击 编辑 按钮修改内部编号和启用状态

6.2 在库工件

显示当前在库的工件清单。

6.3 异常释放

⚠️ 仅管理员可见

强制清空指定库位上的工件信息并释放库位，用于异常情况下的数据修复。

9.1 预警设置

  • 上限阈值：库存高于此值时触发"高于上限"预警

11. 设备调用

11.1 发送指令

手动设置设备序号、动作标志、排/列/层后点击 发送指令 给PLC。

11.2 写入寄存器

在写入区直接修改寄存器值，点击 写入 发送给PLC。

11.3 PLC复位

⚠️ 仅当立库处于故障状态（D4009=3）时可用

点击 执行PLC复位 发送复位指令 00 08 00 00 00 06 01 05 00 64 FF 00 清除故障。

14. 常见问题

14.1 登录失败

现象：输入用户名密码后提示"登录失败"

排查：

  1. 确认API服务是否在运行（端口5000）
  2. 确认数据库连接是否正常
  3. 检查用户名和密码是否正确

14.2 无法连接PLC

现象：设备监控显示"未连接"

排查：

  1. 确认PLC是否开机并联网
  2. 检查 appsettings.json 中的Modbus TCP配置（Host、Port）
  3. 检查网络防火墙是否开放502端口

14.3 入库/出库任务中断

现象：任务执行过程中提示"任务中断"

原因：

  1. 立库进入故障状态（D4009=3）
  2. 立库暂停（D4009=4）
  3. 等待超时（超过60秒）

处理：

  1. 检查PLC故障代码（D4010/D4011）
  2. 排除故障后使用 PLC复位 功能
  3. 重新执行入库/出库操作

14.4 货位编码格式

系统使用格式：N排-N列-N层（例如 1排-2列-3层）

14.5 浏览器兼容性

推荐使用 Chrome、Edge 或 Firefox 最新版本访问系统。
